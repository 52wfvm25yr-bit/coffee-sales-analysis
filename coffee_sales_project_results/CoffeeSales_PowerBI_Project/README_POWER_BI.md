# Coffee Sales — Power BI Project

## Как открыть

1. Распакуйте архив полностью в отдельную папку.
2. Установите актуальную версию Power BI Desktop.
3. В Power BI Desktop включите предварительные функции:
   - Power BI Project (.pbip);
   - Enhanced report format (PBIR), если программа попросит.
4. Дважды щёлкните `CoffeeSales.pbip`.
5. После открытия выполните `Home → Refresh`.
6. Сохраните проект или выберите `File → Save As`, чтобы получить `.pbix`.

## Что находится на странице

- карточка с количеством записей, общей суммой `money`,
  средним `money` и количеством напитков;
- фильтр по напитку;
- фильтр по дню недели;
- количество записей по напиткам;
- сумма `money` по напиткам;
- почасовое количество записей;
- сравнение частей дня.

## Источник данных

Данные встроены непосредственно в Import-модель Power BI.
Путь к CSV менять не требуется.

## Важное ограничение проверки

Структура проекта, JSON и ссылки между файлами проверены автоматически.
В этой среде нет Power BI Desktop и официального валидатора PBIR,
поэтому финальное отображение визуализаций нужно проверить при первом
открытии в Power BI Desktop.

Если Desktop предложит обновить метаданные проекта, разрешите обновление,
после чего сохраните проект.
